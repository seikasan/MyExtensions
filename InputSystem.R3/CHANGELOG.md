# Changelog

## 1.0.2

- Added XML documentation to all public APIs and public implementation members.

## 1.0.1

- Added `ReadValueAsObservable<TValue>()` for continuous value polling.
- Added `WhilePressedAsObservable()` for notifications while an action is held.
- Added `IsPressedAsObservable()` for continuous pressed-state polling.
- Clarified that `PerformedAsObservable()` represents the `performed` event and does not repeat while held.

## 1.0.0

- Initial release.
